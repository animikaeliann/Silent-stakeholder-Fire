# Team notifications — demo-safe simulation

This directory contains draft outbound emails for the gaps in `output/gaps.json`,
generated by `scripts/08_draft_notifications.py` and (optionally) sent by
`scripts/09_send_notifications.py`.

**This is a demo-safe simulation, not a real notification system.** A real
version of this would need the target org's actual opt-in and a verified team
contact list (real distribution-list addresses, confirmation that those teams
want to receive this, whatever internal routing/approval process the org
requires). This hackathon project intentionally does not attempt to obtain or
guess that — the `to_address` fields in the `.json` drafts
(`mobile-client@bluesky-social-app.internal`, etc.) are placeholder addresses
for a fictional internal domain, not real inboxes.

## Default behavior: dry run, zero configuration

```
python scripts/09_send_notifications.py
```

Prints what would be sent and to whom. Sends nothing, writes nothing. This is
what runs with no environment variables set.

## Sending for real (opt-in, three env vars, all required)

Real sending only happens if **all three** of these are set:

- `DEMO_SEND_EMAIL` — your own sending address (read from the environment,
  never hardcoded in the script)
- `DEMO_RECIPIENT_OVERRIDE` — every email goes here, no exceptions, regardless
  of which team a gap was routed to
- `SMTP_HOST` — the script refuses to guess a mail server; without this it
  falls back to a dry run even if the two `DEMO_*` vars above are set

Optional: `SMTP_PORT` (default 587), `SMTP_USERNAME`, `SMTP_PASSWORD`.

Every real send rewrites the subject to
`[DEMO -- would route to: {ORIGINAL_TEAM}] {original subject}` and sends to
`DEMO_RECIPIENT_OVERRIDE` only — never to a gap's routed team address. This was
verified with a mocked SMTP client (see commit history / integration_test.md
convention used elsewhere in this repo) before shipping: every captured
message's `To` header equals the override address, with no exceptions across
all 3 drafts.

```
export DEMO_SEND_EMAIL="you@yourdomain.com"
export DEMO_RECIPIENT_OVERRIDE="you-or-a-test-inbox@yourdomain.com"
export SMTP_HOST="smtp.yourdomain.com"
python scripts/09_send_notifications.py
```
